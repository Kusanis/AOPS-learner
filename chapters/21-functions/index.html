Chapter 21 · Advanced Topics

Functions

A function is a machine: feed it an input and it hands back exactly one output. That single idea ties together everything from lines and parabolas to rounding and distance. In this chapter you'll evaluate, graph and chain functions, find which inputs they accept, spot their symmetries, meet a few unusual ones, and learn to slide and stretch their graphs without recomputing a thing.

Each example climbs from Warm-up to Challenge. Press N for the next step, F for the full solution.
Key methods in this chapter
  • To evaluate $f(\text{something})$, replace every $x$ in the rule by that something, wrapped in parentheses.
  • Given $f(\text{expression in } x)$, either solve for the $x$ that makes the expression equal your input, or substitute $u = $ expression and rewrite in terms of $u$.
  • Vertical line test: a graph is a function exactly when no vertical line meets it twice.
  • Domain: throw out inputs that divide by zero, take even roots of negatives, or take logs of non-positive numbers. Range: ask which outputs can actually occur.
  • $f^n(x)$ means apply $f$ $n$ times, which is not $[f(x)]^n$. Composition $(g\circ f)(x) = g(f(x))$ applies $f$ first, and order matters.
  • Even: $f(-x) = f(x)$ (mirror in the $y$-axis). Odd: $f(-x) = -f(x)$ (half-turn about the origin).
  • $|M| = N$ splits into $M = N$ or $M = -N$. $\lfloor x \rfloor = n$ means $n \le x < n+1$. Piecewise rules apply only on their own pieces.
  • $f(x - h) + k$ shifts right $h$ and up $k$; $a\,f(x)$ stretches vertically by $a$; $f(bx)$ squeezes horizontally by $b$.

21.1 Welcome to the Machine

Hook

You press button B4 on a vending machine and out drops a granola bar. Press B4 again tomorrow: another granola bar. If B4 sometimes gave a granola bar and sometimes a bottle of water, you'd call the machine broken. Mathematicians feel the same way about rules that turn numbers into numbers, and the well-behaved ones get a special name.

Concept

A function is a rule that assigns to each allowed input exactly one output. If the rule is called $f$ and the input is $x$, the output is written $f(x)$, read "$f$ of $x$." The line $y = 2x + 3$ becomes the function $f(x) = 2x + 3$: put in $x = 4$ and the machine returns $f(4) = 11$, every time.

Not every equation describes a function of $x$. The equation $y^2 = x$ gives two values of $y$ when $x = 4$ (namely $2$ and $-2$), so it fails the "exactly one output" requirement. We rescue it by agreeing that $\sqrt{x}$ means only the root that is $\ge 0$.

A function gives one and only one output for each input. To evaluate, substitute: replace every $x$ by the input, in parentheses.

The letter inside the parentheses is just a placeholder. $f(x) = x^2$, $f(t) = t^2$ and $f(\heartsuit) = \heartsuit^2$ all describe the same machine. That's why we may feed it an expression: if $f(x) = x^2$, then $f(a+1) = (a+1)^2$.

Sometimes you're given the machine in disguise, such as $f(x+2) = x^2 + 3x - 1$. The input here is $x + 2$, not $x$. To find $f(5)$, choose the $x$ that makes the input equal $5$.

Turn the crank

If $g(x) = 3x - 5$, find $g(4)$, $g(-2)$ and $g(0)$.

  1. $g(4) = 3(4) - 5 = 7$.

    Replace $x$ by $4$ and compute.

  2. $g(-2) = 3(-2) - 5 = -11$.

    Parentheses around $-2$ keep the sign attached to the input.

  3. $g(0) = 3(0) - 5 = -5$.

    The output at $0$ is where the line crosses the vertical axis.

$g(4) = 7$, $g(-2) = -11$, $g(0) = -5$

Function or not?

Which of these define $y$ as a function of $x$: $y = 2x + 1$, $\;y^2 = x$, $\;x = 5$, $\;y = |x|$?

  1. $y = 2x + 1$ and $y = |x|$ each produce one $y$ for every $x$: functions.

    Each is a recipe that you follow to get a single number.

  2. $y^2 = x$: at $x = 9$, both $y = 3$ and $y = -3$ work. Not a function.

    One input with two outputs is enough to disqualify it.

  3. $x = 5$: the input $5$ is paired with every $y$ at once, and other inputs get nothing. Not a function.

    A vertical line is the most extreme failure: infinitely many outputs for one input.

$y = 2x + 1$ and $y = |x|$ are functions; $y^2 = x$ and $x = 5$ are not.

A fraction machine

If $h(t) = \dfrac{t^2 - 1}{t + 3}$, find $h(-1)$, $h(2)$ and $h(0)$.

  1. $h(-1) = \dfrac{(-1)^2 - 1}{-1 + 3} = \dfrac{0}{2} = 0$.

    A zero numerator with a nonzero denominator gives $0$.

  2. $h(2) = \dfrac{4 - 1}{5} = \dfrac{3}{5}$.

    Substitute into top and bottom separately.

  3. $h(0) = \dfrac{-1}{3} = -\dfrac13$.

    The variable is called $t$ here, but the procedure is identical.

$h(-1) = 0$, $h(2) = \dfrac35$, $h(0) = -\dfrac13$

A ratio of outputs

If $f(x) = 3^x$, find $\dfrac{f(5)}{f(3)}$. Then show that $\dfrac{f(x+2)}{f(x)}$ is the same for every $x$.

  1. $\dfrac{f(5)}{f(3)} = \dfrac{3^5}{3^3} = 3^2 = 9$.

    Same base, so subtract exponents (Chapter 1).

  2. $\dfrac{f(x+2)}{f(x)} = \dfrac{3^{x+2}}{3^x} = 3^2 = 9$.

    The input $x+2$ goes where $x$ was; the $x$'s cancel in the exponent.

$9$, and the ratio $f(x+2)/f(x)$ is always $9$.

Feed it an expression

If $f(x) = x^2 - 2x$, find $f(a + 1)$ and simplify.

  1. $f(a+1) = (a+1)^2 - 2(a+1)$.

    Every $x$ becomes $(a+1)$, parentheses included.

  2. $= a^2 + 2a + 1 - 2a - 2 = a^2 - 1$.

    Expand and collect like terms.

  3. Check with $a = 2$: $f(3) = 9 - 6 = 3$ and $a^2 - 1 = 3$. ✓

    A numerical spot check catches algebra slips.

$f(a+1) = a^2 - 1$

Compare two related inputs

If $f(x) = x^2 + 3x + 1$, simplify $f(2x) - 2f(x)$.

  1. $f(2x) = (2x)^2 + 3(2x) + 1 = 4x^2 + 6x + 1$.

    The input is $2x$, so $x^2$ becomes $(2x)^2 = 4x^2$, not $2x^2$.

  2. $2f(x) = 2x^2 + 6x + 2$.

    Doubling the output doubles every term.

  3. $f(2x) - 2f(x) = 2x^2 - 1$.

    The $6x$ terms cancel; $f(2x)$ and $2f(x)$ are different things.

$2x^2 - 1$

Doubling the input and doubling the output are different operations.

A machine in disguise

Suppose $f(x + 2) = x^2 + 3x - 1$ for all $x$. Find $f(5)$.

  1. We need $x + 2 = 5$, so $x = 3$.

    $f(5)$ means "the output when the input is $5$," and the input here is $x + 2$.

  2. $f(5) = 3^2 + 3(3) - 1 = 17$.

    Now substitute $x = 3$ into the right side.

$f(5) = 17$

Unmask the machine

Again $f(x + 2) = x^2 + 3x - 1$. Find a formula for $f(x)$.

  1. Let $u = x + 2$, so $x = u - 2$. Then $f(u) = (u-2)^2 + 3(u-2) - 1$.

    Rewriting the right side in terms of the actual input lets us read off the rule.

  2. $f(u) = u^2 - 4u + 4 + 3u - 6 - 1 = u^2 - u - 3$.

    Expand and collect.

  3. Rename the placeholder: $f(x) = x^2 - x - 3$. Check: $f(5) = 25 - 5 - 3 = 17$. ✓

    It agrees with the previous example.

$f(x) = x^2 - x - 3$

Name the inside expression $u$, solve for $x$ in terms of $u$, and substitute.

Two equations from one

A function satisfies $f(x) + 2f(1 - x) = 3x$ for every real $x$. Find $f(x)$.

  1. Replace $x$ by $1 - x$: $f(1-x) + 2f(x) = 3(1 - x)$.

    The equation holds for every input, including $1 - x$. Since $1 - (1-x) = x$, the same two unknowns reappear.

  2. Write $A = f(x)$, $B = f(1-x)$: $\;A + 2B = 3x$ and $2A + B = 3 - 3x$.

    Now it's an ordinary system of two linear equations (Chapter 3).

  3. Double the second and subtract the first: $3A = 6 - 9x$, so $A = 2 - 3x$.

    Eliminating $B$ isolates $f(x)$.

  4. Check: $f(x) = 2 - 3x$ gives $f(1-x) = -1 + 3x$, and $(2 - 3x) + 2(-1 + 3x) = 3x$. ✓

    Always check a functional equation in the original.

$f(x) = 2 - 3x$

Substituting a clever input into a functional equation can produce a second equation with the same unknowns.

21.2 Graphing Functions

Hook

A table of values is a handful of snapshots. A graph is the whole movie: in one glance you can see where a function rises, where it falls, where it crosses zero and whether two outputs ever agree. Drawing one takes nothing more than evaluating the function many times.

Concept

To graph $f$, plot every point $(x, f(x))$: the input runs along the horizontal axis and the output is the height. In practice, compute a few points, look for the pattern, and connect them smoothly. Add extra points wherever the shape is unclear, for example near a zero denominator.

Vertical line test: a curve is the graph of a function exactly when every vertical line meets it at most once.

A vertical line $x = c$ collects all the points with input $c$, so two crossings would mean two outputs for one input. Horizontal lines are different: $f(x) = x^2$ gives the output $4$ for both $x = 2$ and $x = -2$, and that's perfectly fine. Many inputs may share an output; one input may not have many outputs.

Where two graphs $y = f(x)$ and $y = g(x)$ cross, the inputs agree and so do the outputs, so the crossing points come from solving $f(x) = g(x)$.

Plot a line from a table

Make a table for $f(x) = 2x - 1$ at $x = -1, 0, 1, 2$ and describe the graph.

  1. $f(-1) = -3$, $f(0) = -1$, $f(1) = 1$, $f(2) = 3$, giving the points $(-1,-3), (0,-1), (1,1), (2,3)$.

    Each input-output pair becomes one point.

  2. Each step of $1$ to the right raises the output by $2$, so the points lie on a line of slope $2$ through $(0, -1)$.

    A constant rate of change means a straight line (Chapter 16).

A straight line with slope $2$ and $y$-intercept $-1$.

A circle fails the test

Is the circle $x^2 + y^2 = 25$ the graph of a function of $x$?

  1. Take the vertical line $x = 3$: $9 + y^2 = 25$, so $y = 4$ or $y = -4$.

    To apply the vertical line test, fix $x$ and count the matching $y$'s.

  2. Two points, $(3, 4)$ and $(3, -4)$, share an input. Not a function.

    One failing line is enough.

No. The line $x = 3$ meets the circle twice.

The top half alone, $y = \sqrt{25 - x^2}$, is a function.

A parabola point by point

Graph $f(x) = x^2 - 4$ using $x = -3, \ldots, 3$. Where does it cross the $x$-axis, and what is its lowest point?

  1. Outputs for $x = -3, -2, -1, 0, 1, 2, 3$: $\;5, 0, -3, -4, -3, 0, 5$.

    Squaring makes $x$ and $-x$ give the same output, so the table is symmetric.

  2. Plot and connect with a smooth U-shaped curve.

    The points rise more and more steeply away from the middle, which a smooth curve captures.

  3. It crosses the $x$-axis at $x = \pm 2$; the lowest point is $(0, -4)$.

    Zeros are where the output is $0$; $x^2 \ge 0$ makes $-4$ the smallest output.

Crosses at $x = -2$ and $x = 2$; lowest point $(0, -4)$.

A cubic with three zeros

Evaluate $f(x) = x^3 - 4x$ at $x = -2, -1, 0, 1, 2$ and sketch its shape.

  1. Outputs: $f(-2) = 0$, $f(-1) = 3$, $f(0) = 0$, $f(1) = -3$, $f(2) = 0$.

    For example $f(-1) = -1 + 4 = 3$.

  2. The graph rises from far left, crosses at $-2$, peaks near $x = -1$, crosses at $0$, dips near $x = 1$, crosses at $2$, then climbs forever.

    For large $|x|$ the $x^3$ term dominates: very negative on the left, very positive on the right.

An S-like curve crossing the $x$-axis at $-2$, $0$ and $2$.

Use a point on the graph

The point $(2, 7)$ lies on the graph of $f(x) = ax^2 - 1$. Find $a$ and then $f(-3)$.

  1. "$(2, 7)$ is on the graph" means $f(2) = 7$: $\;4a - 1 = 7$, so $a = 2$.

    A point on the graph is an input-output pair.

  2. $f(-3) = 2(9) - 1 = 17$.

    With $a$ known, the function is fully determined.

$a = 2$ and $f(-3) = 17$.

Zooming in near a gap

Sketch $f(x) = \dfrac{1}{x}$. What happens near $x = 0$?

  1. Integer points: $(1,1), (2, \tfrac12), (4, \tfrac14)$ and $(-1,-1), (-2,-\tfrac12)$.

    These show the curve flattening toward the $x$-axis far from $0$.

  2. Fractions: $f(\tfrac12) = 2$, $f(\tfrac14) = 4$, $f(\tfrac1{10}) = 10$; and $f(-\tfrac1{10}) = -10$.

    Small inputs give huge outputs, so the graph shoots up just right of $0$ and down just left of $0$.

  3. $x = 0$ has no output, so the graph has two separate branches.

    Division by zero is undefined; the curve never touches the vertical axis.

Two branches, in the first and third quadrants, hugging both axes and never reaching $x = 0$.

Which variable is the function?

Consider $x = y^2 - 2y$. Is $y$ a function of $x$? Is $x$ a function of $y$?

  1. For each $y$, the rule computes exactly one $x$, so $x$ is a function of $y$.

    The equation is already a recipe: start from $y$, get $x$.

  2. At $x = 0$: $y^2 - 2y = 0$, so $y = 0$ or $y = 2$. So $y$ is not a function of $x$.

    The vertical line $x = 0$ meets the curve at $(0,0)$ and $(0,2)$.

$x$ is a function of $y$; $y$ is not a function of $x$.

Where two graphs meet

Find all intersection points of $y = x^2$ and $y = x + 6$.

  1. Set the outputs equal: $x^2 = x + 6$, so $x^2 - x - 6 = 0$.

    At a crossing, the same input gives the same output on both graphs.

  2. $(x - 3)(x + 2) = 0$, so $x = 3$ or $x = -2$.

    Factor the quadratic (Chapter 6).

  3. Outputs: $3^2 = 9$ and $(-2)^2 = 4$, giving $(3, 9)$ and $(-2, 4)$.

    Check with the line: $3 + 6 = 9$, $-2 + 6 = 4$. ✓

$(3, 9)$ and $(-2, 4)$

A line that just touches

For which $k$ does the line $y = 2x + k$ meet the parabola $y = x^2$ at exactly one point? Find that point.

  1. Intersections solve $x^2 = 2x + k$, that is, $x^2 - 2x - k = 0$.

    Counting meeting points means counting real solutions.

  2. Exactly one solution when the discriminant is zero: $(-2)^2 - 4(1)(-k) = 4 + 4k = 0$, so $k = -1$.

    The discriminant $b^2 - 4ac$ decides whether there are $2$, $1$ or $0$ real roots.

  3. Then $x^2 - 2x + 1 = (x-1)^2 = 0$, so $x = 1$ and the point is $(1, 1)$.

    A double root means the line is tangent to the parabola there.

$k = -1$, touching at $(1, 1)$.

Turning "how many crossings" into "how many solutions" lets algebra answer a picture question.

21.3 Inputs and Outputs

Hook

Type $1 \div 0$ or $\sqrt{-4}$ into a calculator and it answers "Error." The machine is telling you that some inputs simply aren't allowed. Knowing in advance which inputs a function accepts, and which outputs it can ever produce, saves you from answers that don't exist.

Concept

The domain of a function is its set of allowed inputs; the range is the set of outputs it actually produces. Unless told otherwise, we use real inputs and real outputs, so we exclude any input that would:

  • make a denominator zero, as in $\dfrac{1}{x-2}$ at $x = 2$;
  • put a negative number under an even root, as in $\sqrt{x}$ for $x < 0$;
  • take the logarithm of zero or a negative number, as in $\log x$ for $x \le 0$.

The range usually takes some thought: $x^2 - 1$ can never go below $-1$, $2^x$ is always positive, and $\dfrac1x$ can be any number except $0$.

Outputs can be fed back in. Applying $f$ repeatedly gives $f(f(x))$, written $f^2(x)$, and in general $f^n(x)$ means $n$ applications. Feeding $f$'s output into a different function $g$ gives the composition:

$$(g \circ f)(x) = g\big(f(x)\big) \qquad\text{(apply } f \text{ first, then } g\text{)}.$$

Warning: $f^2(x) = f(f(x))$ is not $[f(x)]^2$. (The one famous exception is trigonometry, where $\sin^2 x$ conventionally means $(\sin x)^2$.) And in general $g \circ f \ne f \circ g$.

Avoid dividing by zero

Find the domain of $f(x) = \dfrac{5}{x^2 - 9}$.

  1. The denominator is zero when $x^2 = 9$, that is, $x = 3$ or $x = -3$.

    Those are the only inputs that break the formula.

  2. Every other real number is allowed.

    There are no roots or logs to worry about.

All real numbers except $3$ and $-3$.

Keep the square root happy

Find the domain of $g(x) = \sqrt{2x - 6}$.

  1. Need $2x - 6 \ge 0$.

    A square root of a negative number isn't real; zero is fine.

  2. So $x \ge 3$.

    Add $6$, then divide by $2$.

$x \ge 3$

Two conditions at once

Find the domain of $h(x) = \log(x - 2) + \sqrt{8 - x}$.

  1. The log needs $x - 2 > 0$, so $x > 2$.

    Logs accept only positive inputs, and zero is excluded.

  2. The root needs $8 - x \ge 0$, so $x \le 8$.

    Zero under a square root is allowed.

  3. Both must hold: $2 < x \le 8$.

    An input is allowed only if every part of the formula accepts it.

$2 < x \le 8$

Find the range by thinking

Find the ranges of $p(x) = 5 - x^2$ and $q(x) = \dfrac{3}{x + 4}$.

  1. $x^2$ takes every value $\ge 0$, so $5 - x^2$ takes every value $\le 5$.

    Subtracting a nonnegative amount from $5$ can't exceed $5$, and any smaller value is reached.

  2. $q(x) = 3/(x+4)$ is never $0$ (the numerator is $3$), but any other output $y$ occurs at $x = \tfrac{3}{y} - 4$.

    To check a value is in the range, solve for the input that produces it.

Range of $p$: all $y \le 5$. Range of $q$: all reals except $0$.

Run the machine three times

If $f(x) = 3x - 2$, find $f^3(x)$ and $f^3(2)$.

  1. $f^2(x) = f(3x - 2) = 3(3x - 2) - 2 = 9x - 8$.

    Feed the output back in as the new input.

  2. $f^3(x) = f(9x - 8) = 3(9x - 8) - 2 = 27x - 26$.

    One more pass.

  3. $f^3(2) = 54 - 26 = 28$. Check directly: $2 \to 4 \to 10 \to 28$. ✓

    Following one number through is a good test of the formula.

$f^3(x) = 27x - 26$ and $f^3(2) = 28$.

Iterate vs. power

If $f(x) = x^3$, compare $f^2(x)$ with $[f(x)]^2$.

  1. $f^2(x) = f(x^3) = (x^3)^3 = x^9$.

    Apply the cubing machine twice.

  2. $[f(x)]^2 = (x^3)^2 = x^6$.

    Square the single output.

$f^2(x) = x^9$ but $[f(x)]^2 = x^6$; they differ.

Order matters in composition

Let $f(x) = x + 4$ and $g(x) = x^2$. Find $(g \circ f)(x)$ and $(f \circ g)(x)$, and evaluate both at $x = 1$.

  1. $(g \circ f)(x) = g(x + 4) = (x+4)^2 = x^2 + 8x + 16$.

    Add $4$ first, then square.

  2. $(f \circ g)(x) = f(x^2) = x^2 + 4$.

    Square first, then add $4$.

  3. At $x = 1$: $(g\circ f)(1) = 25$ but $(f \circ g)(1) = 5$.

    A single input where they differ proves $g \circ f \ne f \circ g$.

$(g\circ f)(x) = (x+4)^2$, $(f\circ g)(x) = x^2 + 4$; at $x=1$ they give $25$ and $5$.

The one missing output

Find the range of $r(x) = \dfrac{2x + 1}{x - 3}$.

  1. Set $y = \dfrac{2x+1}{x-3}$ and solve for $x$: $\;yx - 3y = 2x + 1$, so $x(y - 2) = 3y + 1$.

    An output $y$ is in the range exactly when some input produces it.

  2. If $y \ne 2$: $x = \dfrac{3y+1}{y-2}$ works (and it's never $3$). If $y = 2$: we'd need $0 = 7$, impossible.

    Division by $y - 2$ is only legal when $y \ne 2$, so that case is checked separately.

  3. Equivalently, $r(x) = 2 + \dfrac{7}{x-3}$, and the fraction is never $0$.

    Splitting off the whole part shows why $2$ is missed.

All real numbers except $2$.

A machine that cycles

Let $f(x) = \dfrac{1}{1 - x}$ (for $x \ne 0, 1$). Find $f^2(x)$ and $f^3(x)$, then compute $f^{100}(3)$.

  1. $f^2(x) = \dfrac{1}{1 - \frac{1}{1-x}} = \dfrac{1-x}{(1-x) - 1} = \dfrac{x - 1}{x}$.

    Multiply top and bottom by $1 - x$ to clear the inner fraction.

  2. $f^3(x) = \dfrac{1}{1 - \frac{x-1}{x}} = \dfrac{x}{x - (x - 1)} = x$.

    Three passes return the original input.

  3. $100 = 3 \cdot 33 + 1$, so $f^{100} = f^{1}$ and $f^{100}(3) = \dfrac{1}{1-3} = -\dfrac12$.

    Every block of three applications cancels out, leaving one.

  4. Check the cycle: $3 \to -\tfrac12 \to \tfrac23 \to 3$. ✓

    Tracing a number confirms the period is $3$.

$f^2(x) = \dfrac{x-1}{x}$, $f^3(x) = x$, and $f^{100}(3) = -\dfrac12$.

When iterating, look for a cycle; then reduce the number of applications by the cycle length.

21.4 Even and Odd

Hook

Fold a sheet of graph paper along the $y$-axis and the two halves of $y = x^2$ land exactly on each other. Now stick a pin through the origin of the graph of $y = x^3$ and spin the paper half a turn: the curve lands on itself. Symmetries like these cut your work in half: know one side, and you know the other.

Concept

Mirror symmetry in the $y$-axis means the height at $-x$ equals the height at $x$. Half-turn symmetry about the origin means the height at $-x$ is the negative of the height at $x$.

$$\text{even: } f(-x) = f(x) \qquad\qquad \text{odd: } f(-x) = -f(x)$$

The names come from powers: $x^2, x^4, x^6$ are even, and $x, x^3, x^5$ are odd. A polynomial with only even powers (a constant counts as $x^0$) is even; one with only odd powers is odd; a mixture is neither. Most functions are neither.

To prove a function is even or odd, simplify $f(-x)$ and compare it with $f(x)$. To disprove, one number is enough: if $f(1) = 2$ and $f(-1) = 0$, then $f$ is neither.

If $f$ is odd and $0$ is in its domain, then $f(0) = -f(0)$, which forces $f(0) = 0$. An odd graph must pass through the origin. Even functions can have any value at $0$.

Test an even polynomial

Is $f(x) = x^4 - 3x^2$ even, odd or neither?

  1. $f(-x) = (-x)^4 - 3(-x)^2 = x^4 - 3x^2$.

    Even powers erase the minus sign.

  2. $f(-x) = f(x)$ for all $x$, so $f$ is even.

    That's exactly the definition.

Even

Test an odd polynomial

Is $g(x) = 2x^3 + x$ even, odd or neither?

  1. $g(-x) = 2(-x)^3 + (-x) = -2x^3 - x$.

    Odd powers keep the minus sign.

  2. $-2x^3 - x = -(2x^3 + x) = -g(x)$, so $g$ is odd.

    Factor out $-1$ to compare with $g(x)$.

Odd

A mixture is neither

Show that $h(x) = x^2 + x$ is neither even nor odd.

  1. $h(1) = 2$ and $h(-1) = 1 - 1 = 0$.

    To disprove a property that must hold for all $x$, one counterexample suffices.

  2. $0 \ne 2$, so not even; $0 \ne -2$, so not odd.

    Even would need $h(-1) = h(1)$; odd would need $h(-1) = -h(1)$.

Neither

Even and odd beyond polynomials

Classify $r(x) = \dfrac{x}{x^2 + 1}$ and $q(x) = \dfrac{1}{x^2 - 4}$.

  1. $r(-x) = \dfrac{-x}{x^2 + 1} = -r(x)$: odd.

    The numerator changes sign; the denominator, built from $x^2$, does not.

  2. $q(-x) = \dfrac{1}{(-x)^2 - 4} = q(x)$: even.

    The only $x$ appears squared. Its domain, all reals except $\pm 2$, is also symmetric.

$r$ is odd; $q$ is even.

A constant spoils oddness

Is $f(x) = x^3 + 1$ odd?

  1. $f(0) = 1$.

    An odd function defined at $0$ must have $f(0) = 0$.

  2. Since $f(0) \ne 0$, $f$ is not odd. (It's not even either: $f(1) = 2$, $f(-1) = 0$.)

    The quick test at $0$ settles oddness instantly.

No; $f$ is neither even nor odd.

Fill in the other side

An odd function has $f(1) = 2$ and $f(2) = -5$, and it is defined at $0$. Find $f(-1) + f(-2) + f(0)$.

  1. $f(-1) = -f(1) = -2$ and $f(-2) = -f(2) = 5$.

    Oddness flips the sign of each output.

  2. $f(0) = 0$.

    Odd functions pass through the origin.

  3. Sum: $-2 + 5 + 0 = 3$.

    Combine.

$3$

Even times odd

If $f$ is even and $g$ is odd, is the product $p(x) = f(x)g(x)$ even, odd or neither?

  1. $p(-x) = f(-x)\,g(-x) = f(x)\cdot\big(-g(x)\big) = -p(x)$.

    Apply each property separately, then collect the single minus sign.

  2. So $p$ is odd. Example: $x^2 \cdot x^3 = x^5$.

    The rule matches the arithmetic of exponents: even $+$ odd $=$ odd.

Odd

Even and odd multiply like signs: even·even and odd·odd are even, even·odd is odd.

Split any function into even and odd parts

Write $f(x) = 2^x$ as the sum of an even function and an odd function.

  1. Let $E(x) = \dfrac{f(x) + f(-x)}{2}$ and $O(x) = \dfrac{f(x) - f(-x)}{2}$. Then $E + O = f$.

    Adding the two fractions, the $f(-x)$ terms cancel and two halves of $f(x)$ remain.

  2. $E(-x) = \dfrac{f(-x) + f(x)}{2} = E(x)$, and $O(-x) = \dfrac{f(-x) - f(x)}{2} = -O(x)$.

    Replacing $x$ by $-x$ swaps $f(x)$ and $f(-x)$.

  3. For $f(x) = 2^x$: $E(x) = \dfrac{2^x + 2^{-x}}{2}$ and $O(x) = \dfrac{2^x - 2^{-x}}{2}$.

    Substitute into the general recipe.

$2^x = \dfrac{2^x + 2^{-x}}{2} + \dfrac{2^x - 2^{-x}}{2}$ (even part plus odd part).

Averaging $f(x)$ with $f(-x)$ extracts the even part; half the difference gives the odd part.

Both at once

Find every function defined for all real $x$ that is both even and odd.

  1. Even gives $f(-x) = f(x)$; odd gives $f(-x) = -f(x)$.

    Write down both conditions.

  2. So $f(x) = -f(x)$, meaning $2f(x) = 0$ and $f(x) = 0$ for every $x$.

    Both expressions equal $f(-x)$, so they equal each other.

Only the zero function $f(x) = 0$.

21.5 Some Special Functions

Hook

Your age is a function of time, but it's a strange one: it stays at $13$ for a whole year and then suddenly jumps to $14$. The distance between two towns doesn't care which town you start from. Postage rates follow one rule up to some weight and a different rule beyond it. None of these fit a tidy formula like $2x + 3$, yet all of them are functions.

Concept

Absolute value. $|x|$ is the distance from $x$ to $0$: $|5| = 5$, $|-5| = 5$. More generally, $|a - b|$ is the distance between $a$ and $b$ on the number line. To remove absolute value signs, split into cases:

$$|x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases} \qquad\qquad |M| = N \;(N \ge 0) \iff M = N \text{ or } M = -N.$$

Floor. The greatest integer function $\lfloor x \rfloor$ is the largest integer that is $\le x$: $\lfloor 3.7 \rfloor = 3$, $\lfloor 5 \rfloor = 5$, and careful, $\lfloor -2.3 \rfloor = -3$. Its partners are the ceiling $\lceil x \rceil$ (smallest integer $\ge x$) and the fractional part $\{x\} = x - \lfloor x \rfloor$, which always lies in $0 \le \{x\} < 1$.

$$\lfloor x \rfloor = n \iff n \le x < n + 1 \qquad (n \text{ an integer}).$$

The floor graph is a staircase. It jumps at every integer, so you can't draw it without lifting your pen: it is not continuous. Closed dots mark included endpoints and open dots excluded ones.

Piecewise functions. Some functions use different formulas on different parts of the number line, written with a brace. The pieces must cover the domain without overlapping, and each formula is used only on its own piece. Absolute value is itself the simplest piecewise function.

Absolute values as distances

Evaluate $|-7| + |3 - 10| - |4|$.

  1. $|-7| = 7$, $|3 - 10| = |-7| = 7$, $|4| = 4$.

    Work inside the bars first, then take the distance from $0$.

  2. $7 + 7 - 4 = 10$.

    Now it's ordinary arithmetic.

$10$

Floors, ceilings and fractional parts

Find $\lfloor 4.9 \rfloor$, $\lfloor -4.9 \rfloor$, $\lfloor \pi \rfloor$, $\lceil -2.5 \rceil$ and $\{-2.5\}$.

  1. $\lfloor 4.9 \rfloor = 4$ and $\lfloor \pi \rfloor = 3$.

    For positive numbers, the floor just chops off the decimals.

  2. $\lfloor -4.9 \rfloor = -5$.

    The floor goes down the number line, and the integer just below $-4.9$ is $-5$.

  3. $\lceil -2.5 \rceil = -2$ and $\{-2.5\} = -2.5 - \lfloor -2.5 \rfloor = -2.5 - (-3) = 0.5$.

    The ceiling goes up. The fractional part is never negative.

$4,\ -5,\ 3,\ -2,\ 0.5$

A linear absolute value equation

Solve $|2x - 5| = 9$.

  1. Either $2x - 5 = 9$ or $2x - 5 = -9$.

    Two numbers have absolute value $9$: $9$ and $-9$.

  2. $2x = 14 \Rightarrow x = 7$, or $2x = -4 \Rightarrow x = -2$.

    Solve each linear equation.

  3. Check: $|14 - 5| = 9$ and $|-4 - 5| = 9$. ✓

    Both work.

$x = 7$ or $x = -2$

Four solutions from two quadratics

Solve $|x^2 - 5x| = 6$.

  1. Case $x^2 - 5x = 6$: $x^2 - 5x - 6 = (x - 6)(x + 1) = 0$, so $x = 6$ or $x = -1$.

    The inside equals $+6$.

  2. Case $x^2 - 5x = -6$: $x^2 - 5x + 6 = (x-2)(x-3) = 0$, so $x = 2$ or $x = 3$.

    The inside equals $-6$; this case is easy to forget.

  3. Check $x = 2$: $|4 - 10| = |-6| = 6$. ✓ (The others check similarly.)

    The explorer above shows the same four crossings at height $6$.

$x = -1, 2, 3, 6$

Equally far from two points

Solve $|x - 3| = |x + 5|$.

  1. $|x - 3|$ is the distance from $x$ to $3$; $|x + 5| = |x - (-5)|$ is the distance to $-5$.

    Reading absolute values as distances often reveals the answer.

  2. The point equally far from $3$ and $-5$ is their midpoint, $\dfrac{3 + (-5)}{2} = -1$.

    On a line, only the midpoint is equidistant from two points.

  3. Algebra agrees: $x - 3 = -(x + 5)$ gives $x = -1$; $x - 3 = x + 5$ has no solution.

    The case split confirms there's exactly one answer.

$x = -1$

Evaluate a piecewise function

Let $f(x) = \begin{cases} x^2, & x \ge 2 \\ 3x - 1, & -1 \le x < 2 \\ -x, & x < -1 \end{cases}$. Find $f(3)$, $f(2)$, $f(0)$ and $f(-4)$.

  1. $3 \ge 2$, so $f(3) = 9$; and $2 \ge 2$, so $f(2) = 4$.

    First decide which piece the input belongs to. The endpoint $2$ belongs to the top piece.

  2. $0$ is in $-1 \le x < 2$, so $f(0) = 3(0) - 1 = -1$.

    Use only the middle formula.

  3. $-4 < -1$, so $f(-4) = -(-4) = 4$.

    The bottom piece applies.

$f(3) = 9$, $f(2) = 4$, $f(0) = -1$, $f(-4) = 4$

Solve a floor equation

Find all real $x$ with $\lfloor 2x + 1 \rfloor = 4$.

  1. $\lfloor y \rfloor = 4$ means $4 \le y < 5$, so $4 \le 2x + 1 < 5$.

    Translate the floor statement into a pair of inequalities.

  2. Subtract $1$: $3 \le 2x < 4$. Divide by $2$: $1.5 \le x < 2$.

    Do the same operation to all three parts (Chapter 22 explains why this is safe).

$1.5 \le x < 2$

Count the zeros of a piecewise function

How many times does $g(x) = \begin{cases} x^2 - 5, & x \ge 2 \\ x + 1, & x < 2 \end{cases}$ cross the $x$-axis?

  1. Top piece: $x^2 - 5 = 0$ gives $x = \pm\sqrt5$. Only $\sqrt5 \approx 2.24$ satisfies $x \ge 2$.

    A solution counts only if it lies in that piece's own region.

  2. Bottom piece: $x + 1 = 0$ gives $x = -1$, and $-1 < 2$. ✓

    Check the region again.

Twice, at $x = -1$ and $x = \sqrt{5}$.

Next in the book: Exercise 21-29.

Two absolute values

Solve $|x - 1| + |x + 2| = 5$.

  1. The insides change sign at $x = 1$ and $x = -2$, so split into $x \ge 1$, $\;-2 \le x < 1$, and $x < -2$.

    Within each region, both absolute values have a fixed sign and can be removed.

  2. $x \ge 1$: $(x-1) + (x+2) = 2x + 1 = 5$, so $x = 2$ ✓.

    Both insides are nonnegative here.

  3. $-2 \le x < 1$: $(1 - x) + (x + 2) = 3 \ne 5$. No solutions.

    Between the two points, the sum of distances is always the gap between them, $3$.

  4. $x < -2$: $(1-x) + (-x-2) = -2x - 1 = 5$, so $x = -3$ ✓.

    Both insides are negative here.

$x = 2$ or $x = -3$

Split the number line at the points where the expressions inside absolute values change sign.

A number plus its floor

Solve $x + \lfloor x \rfloor = 8.6$.

  1. Write $x = n + f$ with $n = \lfloor x \rfloor$ an integer and $0 \le f < 1$. The equation becomes $2n + f = 8.6$.

    Splitting $x$ separates the integer information from the fractional part.

  2. Since $0 \le f < 1$: $7.6 < 2n \le 8.6$. The only even integer there is $8$, so $n = 4$ and $f = 0.6$.

    $2n$ must be an even integer, which pins it down.

  3. $x = 4.6$. Check: $4.6 + 4 = 8.6$. ✓

    Substitute back.

$x = 4.6$

Writing $x = \lfloor x \rfloor + \{x\}$ turns floor equations into integer bookkeeping.

21.6 Transforming a Function

Hook

In a photo editor you can drag a picture, stretch it taller or squeeze it narrower without redrawing a single pixel. Graphs work the same way. Once you know the shape of $y = x^2$ or $y = |x|$, small changes to the formula slide and stretch that shape in predictable ways.

Concept

Start from a known graph $y = f(x)$. Four basic changes:

$f(x) + k$: shift up $k$. $\qquad f(x - h)$: shift right $h$.

$a\,f(x)$: stretch vertically by $a$. $\qquad f(bx)$: squeeze horizontally by $b$.

Changes outside $f$ act on outputs and behave as you'd expect. Changes inside act on inputs and seem backwards: $f(x - 2)$ moves the graph right. Here's why. The new function reaches the height $f(0)$ when $x - 2 = 0$, that is at $x = 2$, so everything happens $2$ units later. Similarly $f(2x)$ reaches $f(4)$ already at $x = 2$, so the graph is squeezed toward the $y$-axis.

Negative factors reflect: $-f(x)$ flips the graph over the $x$-axis, and $f(-x)$ flips it over the $y$-axis.

A point $(p, q)$ on $y = f(x)$ moves to $\left(h + \tfrac{p}{b},\; a q + k\right)$ on $y = a\,f\big(b(x - h)\big) + k$. Tracking a single point, such as a vertex, is the fastest way to place a transformed graph.

A horizontal shift

How is the graph of $y = (x - 3)^2$ related to $y = x^2$? Where is its vertex?

  1. $(x - 3)^2 = f(x - 3)$ with $f(x) = x^2$: a shift right by $3$.

    Subtracting inside the function moves the graph right.

  2. The vertex moves from $(0, 0)$ to $(3, 0)$.

    The output is $0$ when $x - 3 = 0$.

Shifted right $3$; vertex $(3, 0)$.

A vertical shift

Describe $y = |x| - 4$ and find where it crosses the $x$-axis.

  1. It is $|x|$ shifted down $4$, with vertex $(0, -4)$.

    Subtracting outside lowers every output by $4$.

  2. $|x| - 4 = 0$ gives $x = \pm 4$.

    The V now dips below the axis and crosses it twice.

Down $4$; crosses at $x = -4$ and $x = 4$.

Two shifts together

Describe $y = (x + 1)^2 + 2$ relative to $y = x^2$, and give its vertex and range.

  1. $x + 1 = x - (-1)$: shift left $1$. The $+2$ outside: shift up $2$.

    Write the inside as $x - h$ to read the direction correctly.

  2. Vertex $(0,0) \to (-1, 2)$. Since $(x+1)^2 \ge 0$, every output is $\ge 2$.

    Shifting up by $2$ raises the lowest output from $0$ to $2$.

Left $1$, up $2$; vertex $(-1, 2)$; range $y \ge 2$.

Stretch vs. squeeze

Compare $g(x) = 3\sqrt{x}$ and $h(x) = \sqrt{3x}$ at $x = 12$. Which squeeze of $\sqrt{x}$ gives the same graph as $3\sqrt{x}$?

  1. $g(12) = 3\sqrt{12} = 6\sqrt3 \approx 10.39$, but $h(12) = \sqrt{36} = 6$.

    A vertical stretch by $3$ and a horizontal squeeze by $3$ are different here.

  2. $\sqrt{9x} = \sqrt9\,\sqrt{x} = 3\sqrt{x}$.

    Roots split over products (Chapter 1).

$g(12) \approx 10.39$, $h(12) = 6$. Squeezing horizontally by $9$, giving $\sqrt{9x}$, matches $3\sqrt{x}$.

Dividing the input

For $f(x) = x^2$, describe $y = f(x/3)$. Where does the point $(2, 4)$ move?

  1. $f(x/3)$ reaches the value $f(2)$ when $x/3 = 2$, that is at $x = 6$. So $(2, 4) \to (6, 4)$.

    Dividing the input by $3$ means everything happens $3$ times farther out.

  2. It's a horizontal stretch by $3$. Also $(x/3)^2 = \tfrac19 x^2$: the same as a vertical squeeze by $9$.

    For $x^2$, stretching sideways and squashing down look identical.

A horizontal stretch by a factor of $3$; $(2, 4)$ moves to $(6, 4)$.

Build a function from moves

Start with $y = |x|$. Shift right $2$, stretch vertically by $3$, then shift down $1$. Write the new function and find its $x$-intercepts.

  1. Right $2$: $|x - 2|$. Stretch by $3$: $3|x-2|$. Down $1$: $g(x) = 3|x - 2| - 1$.

    Apply the moves in order, each to the previous formula.

  2. Vertex: $(0,0) \to (2, 0) \to (2, 0) \to (2, -1)$.

    The stretch doesn't move a point on the $x$-axis.

  3. $3|x - 2| = 1 \Rightarrow x - 2 = \pm\tfrac13 \Rightarrow x = \tfrac53$ or $x = \tfrac73$.

    Solve the absolute value equation by cases.

$g(x) = 3|x - 2| - 1$, with $x$-intercepts $\tfrac53$ and $\tfrac73$.

Reflect, then shift

Explain how $y = \sqrt{4 - x}$ comes from $y = \sqrt{x}$, and find its domain.

  1. $\sqrt{4 - x} = \sqrt{-(x - 4)}$: this is $f(-x)$, a reflection over the $y$-axis, then shifted right $4$.

    Factor out $-1$ inside so the shift can be read off as $x - 4$.

  2. $\sqrt{x}$ starts at $(0,0)$ and heads right; the new graph starts at $(4, 0)$ and heads left, through $(0, 2)$.

    Check: $\sqrt{4 - 0} = 2$.

  3. Domain: $4 - x \ge 0$, so $x \le 4$.

    Matches the picture: the graph lives to the left of $x = 4$.

Reflect over the $y$-axis, then shift right $4$; domain $x \le 4$.

Track one point through every move

The graph of $y = f(x)$ passes through $(2, 5)$. Which point must lie on $y = 3f(2x - 4) + 1$?

  1. We need $2x - 4 = 2$, so $x = 3$.

    Make the inside equal the one input we know.

  2. Then $y = 3f(2) + 1 = 3(5) + 1 = 16$.

    Outside changes act directly on the known output.

$(3, 16)$

Undo the inside changes to find the new $x$; apply the outside changes to find the new $y$.

Find the moves hidden in a quadratic

Show that $y = 2x^2 - 12x + 13$ is a transformed copy of $y = x^2$. Describe the moves and give the vertex.

  1. Complete the square: $2(x^2 - 6x) + 13 = 2\big[(x-3)^2 - 9\big] + 13 = 2(x - 3)^2 - 5$.

    Writing the quadratic as $a(x - h)^2 + k$ shows the moves directly.

  2. From $x^2$: shift right $3$, stretch vertically by $2$, shift down $5$. Vertex $(3, -5)$.

    Read $h = 3$, $a = 2$, $k = -5$.

  3. Check: at $x = 3$, $2(9) - 36 + 13 = -5$. ✓

    The original formula agrees at the vertex.

$y = 2(x - 3)^2 - 5$: right $3$, stretch by $2$, down $5$; vertex $(3, -5)$.

Every parabola $y = ax^2 + bx + c$ is a shifted and stretched copy of $y = x^2$.
