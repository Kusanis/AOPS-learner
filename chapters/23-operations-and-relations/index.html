Operations and Relations

Addition and multiplication are not sacred; they're just two of the infinitely many ways to combine numbers. Contest problems love to invent new operations with strange symbols, and the only skill needed to use them is careful substitution. The deeper question is which familiar habits, like swapping the order or regrouping, still work. The chapter ends with relations, the "is equal to" and "is parallel to" of mathematics, and the three properties that make a relation behave like equality.

Each example climbs from Warm-up to Challenge. Press N for the next step, F for the full solution.
Key methods in this chapter
  • To use an invented operation, substitute the numbers into its defining formula exactly where the letters were. Work from the innermost parentheses outward.
  • Commutative: $a \star b = b \star a$. Associative: $(a \star b) \star c = a \star (b \star c)$. Distributive: $a \cdot (b + c) = a\cdot b + a\cdot c$; running it backwards is factoring.
  • One counterexample disproves a property; proving it needs algebra that works for all inputs.
  • Identity $e$: $a \star e = e \star a = a$ for every $a$. Find it by solving $a \star e = a$ and checking that the answer doesn't depend on $a$. Inverse of $a$: the $b$ with $a \star b = b \star a = e$.
  • A relation is reflexive ($a \sim a$), symmetric ($a \sim b \Rightarrow b \sim a$) and/or transitive ($a \sim b,\ b \sim c \Rightarrow a \sim c$). All three together make an equivalence relation, which sorts objects into classes.

23.1 What is an Operation?

Hook

A contest problem says: "Define $a \star b = 3a - 2b$. Find $4 \star 5$." There's nothing to look up and no trick to know; the definition tells you everything. Invented operations test only one thing, whether you can follow a recipe precisely, and that's harder than it sounds once parentheses start nesting.

Concept

An operation is a rule that combines quantities to produce a new one. Most important are binary operations, which take two inputs: $+$, $-$, $\times$, $\div$, and exponentiation (written with a superscript rather than a symbol). But you may define new ones however you like. For example, let

$$a \star b = a + b - ab. \qquad\text{Then}\qquad 4 \star 3 = 4 + 3 - 4\cdot 3 = -5.$$

Using an operation means replacing $a$ by the first input and $b$ by the second. The order of the inputs can matter: here $3 \star 4$ happens to equal $4 \star 3$, but for $a \star b = 3a - 2b$ it doesn't.

When operations are combined, evaluate the innermost parentheses first and work outward. Without parentheses, the usual conventions apply: exponents first, then multiplication and division from left to right, then addition and subtraction from left to right.

An operation table lists every result $a \star b$ for a few inputs, with $a$ down the side and $b$ across the top. It's a quick way to get a feel for a new operation.

Follow the recipe

If $a \star b = 3a - 2b$, find $4 \star 5$ and $5 \star 4$.

  1. $4 \star 5 = 3(4) - 2(5) = 12 - 10 = 2$.

    The first input replaces $a$, the second replaces $b$.

  2. $5 \star 4 = 3(5) - 2(4) = 15 - 8 = 7$.

    Swapping the inputs swaps which number gets multiplied by $3$.

$4 \star 5 = 2$ and $5 \star 4 = 7$.

A symmetric recipe

If $a \otimes b = ab + a + b$, find $2 \otimes 3$ and $(-1) \otimes 7$.

  1. $2 \otimes 3 = 6 + 2 + 3 = 11$.

    Substitute $a = 2$, $b = 3$.

  2. $(-1) \otimes 7 = -7 + (-1) + 7 = -1$.

    Parentheses around $-1$ keep the sign straight.

$11$ and $-1$

Parentheses change the answer

If $a \diamond b = a^2 - b$, compute $(2 \diamond 1) \diamond 5$ and $2 \diamond (1 \diamond 5)$.

  1. $2 \diamond 1 = 4 - 1 = 3$, so $(2 \diamond 1) \diamond 5 = 3 \diamond 5 = 9 - 5 = 4$.

    Innermost parentheses first; the result becomes the first input of the next step.

  2. $1 \diamond 5 = 1 - 5 = -4$, so $2 \diamond (1 \diamond 5) = 2 \diamond (-4) = 4 - (-4) = 8$.

    Now the inner result is the second input.

$(2 \diamond 1) \diamond 5 = 4$ but $2 \diamond (1 \diamond 5) = 8$.

An operation with fractions

If $a \ast b = \dfrac{1}{a} - \dfrac{1}{b}$, find $3 \ast 6$ and simplify $a \ast b$ into a single fraction.

  1. $3 \ast 6 = \dfrac13 - \dfrac16 = \dfrac16$.

    Common denominator $6$.

  2. $a \ast b = \dfrac{b}{ab} - \dfrac{a}{ab} = \dfrac{b - a}{ab}$.

    Check: $\dfrac{6 - 3}{18} = \dfrac16$. ✓

$3 \ast 6 = \dfrac16$ and $a \ast b = \dfrac{b - a}{ab}$.

Solve for a missing input

If $a \odot b = 2a + 3b$ and $x \odot 4 = 20$, find $x$.

  1. $x \odot 4 = 2x + 12$.

    Substitute as usual, keeping $x$ as an unknown.

  2. $2x + 12 = 20$, so $x = 4$.

    Now it's an ordinary linear equation.

$x = 4$

Exponents inside an operation

If $a \dagger b = a^b - b^a$, find $2 \dagger 3$ and then $(2 \dagger 3) \dagger 2$.

  1. $2 \dagger 3 = 2^3 - 3^2 = 8 - 9 = -1$.

    Substitute carefully: $a^b$ is $2^3$, while $b^a$ is $3^2$.

  2. $(-1) \dagger 2 = (-1)^2 - 2^{-1} = 1 - \dfrac12 = \dfrac12$.

    Negative exponents mean reciprocals (Chapter 1).

$2 \dagger 3 = -1$ and $(2 \dagger 3) \dagger 2 = \dfrac12$.

The unknown appears twice

If $a \triangledown b = ab + a - b$, find all $x$ with $x \triangledown x = x \triangledown 2$.

  1. $x \triangledown x = x^2 + x - x = x^2$.

    Both inputs are $x$.

  2. $x \triangledown 2 = 2x + x - 2 = 3x - 2$.

    Here $a = x$ and $b = 2$.

  3. $x^2 = 3x - 2 \Rightarrow (x - 1)(x - 2) = 0$, so $x = 1$ or $x = 2$.

    Check $x = 1$: $1 \triangledown 1 = 1$ and $1 \triangledown 2 = 2 + 1 - 2 = 1$. ✓

$x = 1$ or $x = 2$

A long chain with a hidden pattern

Let $a \oplus b = a + b + ab$. Evaluate $1 \oplus 2 \oplus 3 \oplus \cdots \oplus 9$, working from left to right.

  1. Add $1$: $1 + (a \oplus b) = 1 + a + b + ab = (1 + a)(1 + b)$.

    Factoring by grouping reveals that $\oplus$ is ordinary multiplication in disguise.

  2. Each new step multiplies "one more than the running total" by one more than the new number. So $1 + (\text{answer}) = (1+1)(1+2)\cdots(1+9) = 2 \cdot 3 \cdots 10$.

    Apply the identity repeatedly: if $1 + T = P$, then $1 + (T \oplus k) = P(1 + k)$.

  3. $2 \cdot 3 \cdots 10 = 10! = 3{,}628{,}800$, so the answer is $3{,}628{,}799$.

    Subtract the $1$ we added at the start.

$3{,}628{,}799$

If an operation looks messy, try shifting the inputs (here by $1$) to reveal a familiar operation underneath.

23.2 Properties of Operations

Hook

Socks then shoes works; shoes then socks doesn't. Adding $3$ and then $5$ gives the same total as adding $5$ and then $3$. Some combinations care about order and some don't. With ordinary arithmetic we use these freedoms constantly, often without noticing. Invented operations force us to ask, each time, which freedoms we actually have.

Concept

Commutative: $a \star b = b \star a$ for all $a, b$. (Addition and multiplication yes; subtraction and division no.)

Associative: $(a \star b) \star c = a \star (b \star c)$ for all $a, b, c$. Then parentheses can be dropped entirely.

Distributive ($\star$ over $\circ$): $a \star (b \circ c) = (a \star b) \circ (a \star c)$. The key example is $a(b + c) = ab + ac$.

Running the distributive law backwards, $ab + ac = a(b + c)$, is factoring. It turns $45 \cdot 33 + 45 \cdot 67$ into $45 \cdot 100$.

An identity is a number $e$ with $a \star e = e \star a = a$ for every $a$: $0$ for addition, $1$ for multiplication. An operation can have at most one identity: if $e_1$ and $e_2$ were both identities, then $e_1 \star e_2$ would equal both $e_2$ and $e_1$. If there is an identity, the inverse of $a$ is a $b$ with $a \star b = b \star a = e$, like $-a$ for addition and $\tfrac1a$ for multiplication.

To show a property fails, one counterexample is enough. To show it holds, you need an argument that works for all inputs, usually by expanding both sides.

One counterexample suffices

Is $a \star b = a + 2b$ commutative?

  1. $1 \star 2 = 1 + 4 = 5$, but $2 \star 1 = 2 + 2 = 4$.

    Try small, different inputs.

  2. Since $5 \ne 4$, the operation is not commutative.

    "For all $a, b$" fails as soon as one pair fails.

No: $1 \star 2 = 5$ but $2 \star 1 = 4$.

Distribute backwards

Compute $37 \cdot 99 + 37$ mentally.

  1. $37 \cdot 99 + 37 \cdot 1 = 37(99 + 1)$.

    Factoring: both terms share the factor $37$.

  2. $= 37 \cdot 100 = 3700$.

    Multiplying by $100$ is easy.

$3700$

Distribute twice

Expand $(x + 3)(x - 5)$ using only the distributive law.

  1. Treat $(x - 5)$ as one number: $(x + 3)(x - 5) = x(x - 5) + 3(x - 5)$.

    Distribute the whole factor $(x - 5)$ over the sum $x + 3$.

  2. $= x^2 - 5x + 3x - 15 = x^2 - 2x - 15$.

    Distribute again in each piece, then combine like terms.

$x^2 - 2x - 15$

Next in the book: Example 23-3.

Prove two properties

Show that $a \circ b = a + b + ab$ is commutative and associative.

  1. $b \circ a = b + a + ba = a + b + ab = a \circ b$. Commutative.

    Ordinary addition and multiplication are commutative, so the formula is symmetric.

  2. $(a \circ b) \circ c = (a + b + ab) + c + (a + b + ab)c = a + b + c + ab + bc + ca + abc$.

    Treat $a \circ b$ as the first input and expand.

  3. $a \circ (b \circ c) = a + (b + c + bc) + a(b + c + bc)$, which expands to the same expression.

    The result is symmetric in $a$, $b$, $c$, so the grouping can't matter.

Both properties hold for all $a, b, c$.

Find the identity and inverses

For $a \circ b = a + b - 4$, find the identity, and the inverse of $3$.

  1. Solve $a \circ e = a$: $a + e - 4 = a$, so $e = 4$. Also $4 \circ a = a$. ✓

    The value of $e$ must not depend on $a$, and it must work on both sides.

  2. Inverse of $a$: $a + x - 4 = 4$, so $x = 8 - a$. For $a = 3$: $x = 5$.

    Check: $3 \circ 5 = 3 + 5 - 4 = 4 = e$. ✓

Identity $4$; the inverse of $3$ is $5$ (in general $8 - a$).

Which way does distributing work?

Multiplication distributes over addition. Does addition distribute over multiplication, that is, is $a + bc = (a + b)(a + c)$ always?

  1. Try $a = 1$, $b = 2$, $c = 3$: left $1 + 6 = 7$; right $3 \cdot 4 = 12$.

    The pattern "$a \star (b \circ c) = (a \star b) \circ (a \star c)$" with $\star = +$ and $\circ = \times$.

  2. $7 \ne 12$, so no.

    Distributivity is a one-way street for ordinary arithmetic.

No. For example, $1 + 2\cdot 3 = 7$ but $(1+2)(1+3) = 12$.

The averaging operation

Let $a \circ b = \dfrac{a + b}{2}$. Is it commutative? Associative? Does it have an identity?

  1. Commutative: $\dfrac{a + b}{2} = \dfrac{b + a}{2}$. Yes.

    The formula is symmetric.

  2. $(0 \circ 0) \circ 4 = 0 \circ 4 = 2$, but $0 \circ (0 \circ 4) = 0 \circ 2 = 1$. Not associative.

    Averaging twice weights the numbers unequally depending on the grouping.

  3. $\dfrac{a + e}{2} = a$ forces $e = a$, which changes with $a$. No identity.

    An identity must be a single number that works for every input.

Commutative, not associative, no identity.

Inverses solve equations

Suppose $\star$ is associative with identity $e$, and $a$ has an inverse $b$. Show that $a \star x = c$ has exactly one solution, $x = b \star c$. Then use it to solve $3 \circ x = 10$ for $a \circ b = a + b - 4$.

  1. If $a \star x = c$, then $x = e \star x = (b \star a) \star x = b \star (a \star x) = b \star c$.

    Insert $e = b \star a$, regroup using associativity, then substitute $a \star x = c$. Any solution must equal $b \star c$.

  2. Conversely $a \star (b \star c) = (a \star b) \star c = e \star c = c$, so $b \star c$ really is a solution.

    Showing uniqueness and existence are separate tasks.

  3. For $\circ$: the inverse of $3$ is $5$, so $x = 5 \circ 10 = 5 + 10 - 4 = 11$. Check: $3 \circ 11 = 10$. ✓

    The identity and inverse come from the earlier example.

$x = b \star c$ is the unique solution; for the example, $x = 11$.

Associativity plus inverses let you "divide" by an element, exactly as you do in ordinary algebra.

An identity in disguise

Let $a \star b = ab - 2a - 2b + 6$. Find the identity, and find which numbers have inverses.

  1. Factor: $ab - 2a - 2b + 4 = (a - 2)(b - 2)$, so $a \star b = (a - 2)(b - 2) + 2$.

    Shifting by $2$ turns $\star$ into multiplication, just as in the previous section's challenge.

  2. Need $(a - 2)(e - 2) + 2 = a$, i.e. $(a - 2)(e - 2) = a - 2$ for all $a$. So $e - 2 = 1$ and $e = 3$.

    Check: $a \star 3 = (a-2)(1) + 2 = a$. ✓

  3. Inverse: $(a - 2)(x - 2) + 2 = 3$ gives $x = 2 + \dfrac{1}{a - 2}$, valid for every $a \ne 2$. But $2 \star x = 2$ for all $x$, never $3$.

    The number $2$ plays the role of $0$ in multiplication: it has no inverse.

Identity $3$; every $a \ne 2$ has inverse $2 + \dfrac{1}{a-2}$, and $2$ has none.

23.3 Relations

Hook

"Is taller than," "is a sibling of," "has the same birthday as," "is parallel to": each takes two things and says yes or no. Some of these act a lot like the equals sign and some don't. If Ana has the same birthday as Ben, and Ben has the same birthday as Cleo, then Ana and Cleo share a birthday. Try the same reasoning with "is a friend of" and it falls apart.

Concept

A relation on a set of objects is a rule that, for each ordered pair $(a, b)$, says whether $a$ is related to $b$, written $a \sim b$. Examples: $=$, $<$, $\le$, "divides," congruence of triangles, parallel lines. Three properties matter most:

Reflexive: $a \sim a$ for every $a$.

Symmetric: whenever $a \sim b$, also $b \sim a$.

Transitive: whenever $a \sim b$ and $b \sim c$, also $a \sim c$.

Equality has all three. So does triangle congruence. "Greater than" is transitive but neither reflexive nor symmetric. A relation with all three properties is an equivalence relation. It behaves like $=$ in that it splits the objects into separate classes: everything in a class is related to everything else in that class, and to nothing outside it.

Each property is a "for every" statement. A single failure, such as one object not related to itself, is enough to break it.

Check "less than or equal to"

For real numbers, is $\le$ reflexive? Symmetric? Transitive?

  1. Reflexive: $a \le a$ always. Yes.

    The "or equal" part makes it work.

  2. Symmetric: $2 \le 5$ but $5 \not\le 2$. No.

    One counterexample settles it.

  3. Transitive: $a \le b$ and $b \le c$ give $a \le c$. Yes.

    Chain the inequalities: $a \le b \le c$.

Reflexive and transitive, but not symmetric.

An everyday equivalence relation

On a group of people, let $a \sim b$ mean "$a$ was born in the same calendar month as $b$." Is this an equivalence relation?

  1. Reflexive: everyone shares a birth month with themselves. Symmetric: if $a$'s month matches $b$'s, then $b$'s matches $a$'s.

    "Same as" statements are automatically reflexive and symmetric.

  2. Transitive: if $a$ and $b$ share a month, and $b$ and $c$ do, all three have $b$'s month.

    Matching is passed along through $b$.

Yes. The classes are the (at most $12$) groups of people born in each month.

"Has the same ___ as" is always an equivalence relation.

Divisibility

On the positive integers, let $a \sim b$ mean "$a$ divides $b$." Which properties hold?

  1. Reflexive: $a = 1 \cdot a$, so $a$ divides $a$. Yes.

    Every number is a multiple of itself.

  2. Symmetric: $2$ divides $4$, but $4$ doesn't divide $2$. No.

    A counterexample.

  3. Transitive: if $b = ka$ and $c = mb$, then $c = (mk)a$. Yes.

    Write each divisibility as an equation and substitute.

Reflexive and transitive, not symmetric.

"Close to" isn't transitive

On real numbers, let $a \sim b$ mean $|a - b| \le 1$. Which properties hold?

  1. Reflexive: $|a - a| = 0 \le 1$. Symmetric: $|b - a| = |a - b|$. Both yes.

    Distance is zero from a point to itself, and the same in both directions.

  2. Transitive: $0 \sim 0.8$ and $0.8 \sim 1.6$, but $|0 - 1.6| = 1.6 > 1$. No.

    Being close is not passed along: small gaps can add up.

Reflexive and symmetric, not transitive.

Same remainder

On the integers, let $a \sim b$ mean "$a - b$ is divisible by $4$." Show it's an equivalence relation, and name the class containing $2026$.

  1. Reflexive: $a - a = 0 = 4 \cdot 0$. Symmetric: if $a - b = 4k$ then $b - a = 4(-k)$.

    Write "divisible by $4$" as "equals $4$ times an integer."

  2. Transitive: $a - b = 4k$ and $b - c = 4m$ add to $a - c = 4(k + m)$.

    Adding the two equations cancels $b$.

  3. $2026 = 4 \cdot 506 + 2$, so $2026$ is in the class $\{\ldots, -6, -2, 2, 6, 10, \ldots\}$ of integers with remainder $2$.

    Two integers are related exactly when they leave the same remainder on division by $4$ (Chapter 5).

An equivalence relation with four classes (remainders $0, 1, 2, 3$); $2026$ has remainder $2$.

Differ by a whole number

On the real numbers, let $a \sim b$ mean $a - b$ is an integer. Is it an equivalence relation? Describe the classes.

  1. $a - a = 0$ is an integer; if $a - b = n$ then $b - a = -n$; if $a - b = n$ and $b - c = m$ then $a - c = n + m$.

    Integers are closed under negation and addition, which gives all three properties.

  2. $a \sim b$ exactly when $a$ and $b$ have the same fractional part, $\{a\} = \{b\}$.

    Write $a = \lfloor a \rfloor + \{a\}$ (Chapter 21); the integer parts cancel only if the fractional parts agree.

Yes. Each class is $\{\ldots, t - 1, t, t + 1, \ldots\}$ for one value $0 \le t < 1$, e.g. $\{\ldots, -0.7, 0.3, 1.3, 2.3, \ldots\}$.

A single object can spoil reflexivity

On the integers, let $a \sim b$ mean $ab > 0$. Which properties hold? What changes if we remove $0$?

  1. Reflexive fails: $0 \cdot 0 = 0$, which is not $> 0$. (Every other $a$ has $a^2 > 0$.)

    "For every $a$" means even one exception breaks it.

  2. Symmetric: $ab = ba$. Transitive: $ab > 0$ and $bc > 0$ mean $a, b$ share a sign and $b, c$ share a sign, so $a, c$ share a sign and $ac > 0$.

    Positive product means same sign.

  3. On the nonzero integers it's an equivalence relation with two classes: positives and negatives.

    Removing the troublemaker restores reflexivity.

Symmetric and transitive but not reflexive on all integers; an equivalence relation on the nonzero integers.

A tempting false proof

"If $\sim$ is symmetric and transitive, it's reflexive: from $a \sim b$, symmetry gives $b \sim a$, and transitivity gives $a \sim a$." Find the flaw and a counterexample.

  1. The argument assumes $a$ is related to something. If $a$ is related to nothing, we can't start.

    Reflexivity must hold for every $a$, including lonely ones.

  2. On $\{1, 2, 3\}$, let the related pairs be $(1,1), (1,2), (2,1), (2,2)$ only.

    Build a relation where $3$ is related to nothing.

  3. Symmetric: yes. Transitive: every chain stays within $\{1, 2\}$, where all pairs are present. But $3 \not\sim 3$.

    Check each property directly on the small set.

The proof fails for elements related to nothing; the relation above is symmetric and transitive but not reflexive.

Watch for hidden assumptions such as "pick some $b$ with $a \sim b$."

Counting relations

How many relations on $\{1, 2, 3\}$ are reflexive and symmetric? How many of those are equivalence relations?

  1. Reflexive forces $1 \sim 1$, $2 \sim 2$, $3 \sim 3$. Symmetric means the pairs $\{1,2\}, \{1,3\}, \{2,3\}$ are each related in both directions or neither.

    The only free choices are the three unordered pairs.

  2. Each pair is in or out: $2^3 = 8$ relations.

    Multiplication principle (Chapter 25).

  3. Transitive fails exactly when two pairs sharing a number are chosen without the third, which happens in $3$ of the $8$. So $8 - 3 = 5$ are equivalence relations.

    The $5$ survivors: no pairs, any one pair ($3$ ways), or all three.

$8$ reflexive symmetric relations, of which $5$ are equivalence relations.

Equivalence relations match the ways to split the set into classes: $\{1\}\{2\}\{3\}$, three ways to pair two, and $\{1,2,3\}$.
