Inequalities

An equation pins a quantity down to a few values; an inequality hands you a whole stretch of the number line, or a whole region of the plane. In this chapter you'll learn which moves keep an inequality true and which ones flip it, shade half-planes, read sign charts for quadratics and fractions, unwrap absolute values, and squeeze surprising results out of the humble fact that squares are never negative.

Each example climbs from Warm-up to Challenge. Press N for the next step, F for the full solution.
Key methods in this chapter
  • Adding or subtracting anything, or multiplying or dividing by a positive number, keeps the inequality. Multiplying or dividing by a negative number reverses it.
  • Inequalities pointing the same way may be added, never subtracted. Taking reciprocals of two numbers with the same sign reverses the inequality.
  • A linear inequality in $x$ and $y$ is a half-plane: draw the boundary line (dashed if strict, solid if not) and test a point.
  • For polynomial or rational inequalities: move everything to one side, factor, mark the zeros, and read signs off a sign chart. Never multiply through by an expression whose sign you don't know.
  • Interval notation: $[a, b]$ includes endpoints, $(a, b)$ excludes them, $\infty$ always gets a parenthesis, and $\cup$ means "or."
  • $|x - c| < r \iff c - r < x < c + r$, and $|x - c| > r \iff x < c - r$ or $x > c + r$. Isolate the absolute value first.
  • The trivial inequality $x^2 \ge 0$, with equality only at $x = 0$: complete the square to find minima, and rewrite claims as "a square is $\ge 0$" to prove them.

22.1 What They Do

Hook

On a winter morning it's $-2^\circ$ in one town and $-8^\circ$ in another. The first town is warmer: $-2 > -8$. But ask "how many degrees below zero?" and the answers are $2$ and $8$, with $2 < 8$. Flipping the sign of both numbers flipped the comparison. That one surprise is most of what makes inequalities different from equations.

Concept

A strict inequality ($<$ or $>$) rules out equality; a nonstrict one ($\le$ or $\ge$) allows it. So $5 \ge 5$ is true and $5 > 5$ is false. A shorthand like $x, y, z > -17$ means each variable is separately greater than $-17$; it says nothing about how $x$, $y$ and $z$ compare with each other.

Safe moves: add or subtract the same number on both sides; multiply or divide both sides by the same positive number.

Flip the sign: when you multiply or divide both sides by a negative number. $\;x < y \Rightarrow -x > -y$.

Multiplying both sides by $0$ destroys all information, and dividing by $0$ is never allowed. Two inequalities pointing the same way may be added: $a < c$ and $b < d$ give $a + b < c + d$. They may not be subtracted. For positive numbers you may also multiply them ($0 < a < c$ and $0 < b < d$ give $ab < cd$), and squaring or taking square roots preserves order.

Reciprocals: if $a$ and $b$ have the same sign, then $a < b \Rightarrow \dfrac1a > \dfrac1b$. If $a < 0 < b$, then $\dfrac1a < 0 < \dfrac1b$ and the order stays.

True or false?

Decide which are true: (a) $-7 > -2$, (b) $4 \ge 4$, (c) $-0.5 < -0.25$, (d) $3 \le 2$.

  1. (a) False: $-7$ lies to the left of $-2$, so $-7 < -2$.

    On the number line, "greater" means "farther right."

  2. (b) True: $\ge$ allows equality.

    The bar under the sign means "or equal."

  3. (c) True: $-0.5$ is farther left. (d) False.

    Among negatives, the one with the larger size is the smaller number.

(b) and (c) are true; (a) and (d) are false.

Divide by a negative

Solve $5 - 3x < 11$.

  1. Subtract $5$: $-3x < 6$.

    Subtracting from both sides is always safe.

  2. Divide by $-3$ and flip: $x > -2$.

    Dividing by a negative reverses the inequality.

  3. Check $x = 0$: $5 < 11$ ✓. Check $x = -3$: $14 < 11$ ✗.

    Test one value on each side of $-2$ to confirm the direction.

$x > -2$

Add, but don't subtract

If $2 < a < 5$ and $-3 < b < 1$, find the possible values of $a + b$ and of $a - b$.

  1. Add the inequalities: $2 + (-3) < a + b < 5 + 1$, so $-1 < a + b < 6$.

    Inequalities pointing the same way may be added term by term.

  2. For $a - b$, first negate $b$: $-1 < -b < 3$ (the signs flip).

    Subtracting an inequality is really adding its negative, and negating reverses it.

  3. Add: $2 + (-1) < a - b < 5 + 3$, so $1 < a - b < 8$.

    Smallest $a - b$ uses the smallest $a$ and the largest $b$.

$-1 < a + b < 6$ and $1 < a - b < 8$.

Reciprocals reverse

If $2 < x < 5$, what are the possible values of $\dfrac1x$? And if $-4 < y < -1$?

  1. All values are positive, so the inequality reverses: $\dfrac15 < \dfrac1x < \dfrac12$.

    A bigger positive denominator makes a smaller fraction.

  2. All values of $y$ are negative, so again reverse: $-1 < \dfrac1y < -\dfrac14$.

    Check endpoints: $y = -4$ gives $-\tfrac14$ and $y = -1$ gives $-1$.

$\dfrac15 < \dfrac1x < \dfrac12$ and $-1 < \dfrac1y < -\dfrac14$.

Multiply positive ranges

If $1 < a < 3$ and $2 < b < 4$, find the possible values of $ab$.

  1. Everything is positive, so multiply the lower ends and the upper ends: $1 \cdot 2 < ab < 3 \cdot 4$.

    For positive numbers, bigger factors give a bigger product.

  2. So $2 < ab < 12$.

    Both ends can be approached as closely as we like.

$2 < ab < 12$

When a negative sneaks in

If $-1 < a < 3$ and $2 < b < 4$, find the possible values of $ab$.

  1. Multiplying ends naively gives $-2 < ab < 12$, but that's wrong.

    The rule "multiply the ends" needs all numbers positive.

  2. Most negative: $a$ near $-1$ with $b$ near $4$, giving values near $-4$. Most positive: $a$ near $3$ with $b$ near $4$, near $12$.

    A negative $a$ times a larger $b$ is more negative.

  3. So $-4 < ab < 12$. (For fixed $b > 0$, $ab$ moves steadily with $a$, so all values in between occur.)

    Check the extremes by thinking about each sign case.

$-4 < ab < 12$

With mixed signs, check every combination of endpoints instead of multiplying blindly.

Squaring a range that straddles zero

If $-3 < x < 2$, what values can $x^2$ take?

  1. Squaring the endpoints gives $9$ and $4$, but $x = 0$ is allowed, giving $x^2 = 0$.

    Squaring preserves order only for nonnegative numbers.

  2. Split: for $0 \le x < 2$, $0 \le x^2 < 4$; for $-3 < x < 0$, $0 < x^2 < 9$.

    On the negative piece, $|x| < 3$, so $x^2 < 9$.

  3. Together: $0 \le x^2 < 9$.

    Combine the two pieces.

$0 \le x^2 < 9$

Prove an inequality between fractions

Show that if $a > b > 0$, then $\dfrac{a}{a+1} > \dfrac{b}{b+1}$.

  1. Both denominators are positive, so multiplying by $(a+1)(b+1)$ keeps the direction: the claim is equivalent to $a(b+1) > b(a+1)$.

    It's safe to clear denominators only because we know they're positive.

  2. Expand: $ab + a > ab + b$, which is equivalent to $a > b$. True.

    Each step can be reversed, so the original claim holds.

It follows because $a(b+1) - b(a+1) = a - b > 0$.

Compare two tiny differences

Without a calculator, decide which is larger: $\sqrt{11} - \sqrt{10}$ or $\sqrt{10} - 3$.

  1. Multiply by conjugates: $\sqrt{11} - \sqrt{10} = \dfrac{1}{\sqrt{11} + \sqrt{10}}$ and $\sqrt{10} - \sqrt9 = \dfrac{1}{\sqrt{10} + 3}$.

    $(\sqrt{11} - \sqrt{10})(\sqrt{11} + \sqrt{10}) = 11 - 10 = 1$, and similarly for the other.

  2. $\sqrt{11} + \sqrt{10} > \sqrt{10} + 3$, since $\sqrt{11} > 3$.

    Compare the denominators instead, which is easy.

  3. Taking reciprocals of positive numbers reverses: $\dfrac{1}{\sqrt{11}+\sqrt{10}} < \dfrac{1}{\sqrt{10}+3}$.

    A larger positive denominator gives a smaller fraction.

$\sqrt{10} - 3$ is larger.

Rewrite quantities so that one simple comparison, plus a known flip rule, settles the question.

22.2 Linear Inequalities

Hook

Notebooks cost 3 dollars and pens cost 1 dollar, and you have at most 12 dollars. If you buy $x$ notebooks and $y$ pens, you need $3x + y \le 12$. The equation $3x + y = 12$ is a single line, the purchases that spend every cent. The inequality is every affordable purchase: a whole region on one side of that line.

Concept

One variable. Solve exactly as for an equation, flipping the sign whenever you multiply or divide by a negative. Show the answer on a number line: an open circle for an excluded endpoint ($<$, $>$), a filled circle for an included one ($\le$, $\ge$).

Two variables. Consider $x - 4y - 3 > 0$. For each constant $k$, the points with $x - 4y - 3 = k$ form a line, and all these lines are parallel (same $x$ and $y$ coefficients). As $k$ increases they sweep steadily across the plane. So the points with $k > 0$ fill everything on one side of the line $k = 0$.

The solution of a linear inequality in $x$ and $y$ is a half-plane. Draw the boundary line, dashed for $<, >$ and solid for $\le, \ge$. Then plug in a test point not on the line, such as $(0,0)$: shade its side if it works, the other side if not.

For a system of inequalities, the solution is the overlap of all the half-planes, often a polygon.

Solve and graph

Solve $4x - 7 \ge 9$ and describe the graph.

  1. $4x \ge 16$, so $x \ge 4$.

    Add $7$, then divide by the positive number $4$; no flip.

  2. Graph: a filled circle at $4$ with the ray shaded to the right.

    The endpoint is included because of $\ge$.

$x \ge 4$

An open circle

Solve $3 - 2x > 11$.

  1. $-2x > 8$.

    Subtract $3$.

  2. $x < -4$: an open circle at $-4$, shaded to the left.

    Dividing by $-2$ flips the sign; strictness gives the open circle.

$x < -4$

A double inequality

Solve $-5 \le 3x + 1 < 10$. How many integers satisfy it?

  1. Subtract $1$ from all three parts: $-6 \le 3x < 9$.

    Whatever you do, do it to every part.

  2. Divide by $3$: $-2 \le x < 3$.

    Positive divisor, no flips.

  3. Integers: $-2, -1, 0, 1, 2$.

    $-2$ is included; $3$ is not.

$-2 \le x < 3$; five integers.

Two conditions at once

Find all $x$ with $2x + 3 > x - 1$ and $5 - x \ge 2x - 4$.

  1. First: $x > -4$.

    Subtract $x$ and $3$ from both sides.

  2. Second: $9 \ge 3x$, so $x \le 3$.

    Add $x$ and $4$ to both sides, then divide by $3$.

  3. Both: $-4 < x \le 3$.

    "And" means the overlap of the two solution sets.

$-4 < x \le 3$

Shade a half-plane

Graph $y > 2x - 1$.

  1. Boundary $y = 2x - 1$: slope $2$, $y$-intercept $-1$. Draw it dashed.

    The inequality is strict, so the line itself is excluded.

  2. Test $(0, 0)$: $0 > -1$ is true. Shade the side containing the origin, above the line.

    One test point decides the whole half-plane.

The region above the dashed line $y = 2x - 1$.

Watch the flip when solving for $y$

Graph $2x - 3y \le 6$.

  1. Boundary $2x - 3y = 6$ passes through $(3, 0)$ and $(0, -2)$. Draw it solid.

    Intercepts are the quickest points to find; $\le$ includes the line.

  2. Test $(0,0)$: $0 \le 6$ ✓, so shade the origin's side.

    The origin isn't on the line, so it's a valid test point.

  3. Solving for $y$ agrees: $-3y \le 6 - 2x$ gives $y \ge \tfrac23 x - 2$, which is above the line.

    Dividing by $-3$ flips $\le$ to $\ge$. Forgetting that flip would shade the wrong side.

The line $y = \tfrac23x - 2$ and everything above it.

A triangle of solutions

Describe the region $x + y \le 4$, $x \ge 0$, $y \ge 0$. Find its area and the number of points in it with integer coordinates.

  1. The overlap is the triangle with vertices $(0,0)$, $(4,0)$, $(0,4)$, area $\tfrac12 \cdot 4 \cdot 4 = 8$.

    Each inequality cuts the plane in half; together they enclose a triangle.

  2. Lattice points: for $x = 0, 1, 2, 3, 4$, $y$ runs from $0$ to $4 - x$, giving $5 + 4 + 3 + 2 + 1 = 15$.

    Count column by column; boundary points count because all inequalities are nonstrict.

A triangle of area $8$ containing $15$ lattice points.

The area of a feasible region

Find the area of the region defined by $x \ge 0$, $y \ge 0$, $y \le 4 - x$ and $y \ge x - 2$.

  1. Corners: $(0,0)$; $(2, 0)$ where $y = x - 2$ meets $y = 0$; $(3, 1)$ where $x - 2 = 4 - x$; and $(0, 4)$.

    Corners of the overlap are where pairs of boundary lines meet and all other inequalities hold.

  2. It's the triangle $(0,0), (4,0), (0,4)$ of area $8$ with the small triangle $(2,0), (4,0), (3,1)$ of area $\tfrac12 \cdot 2 \cdot 1 = 1$ removed.

    The constraint $y \ge x - 2$ slices a corner off the triangle from the previous example.

  3. Area $= 8 - 1 = 7$.

    Subtract.

$7$

Best value on a region

On the region from the previous example, find the largest value of $3x + 2y$.

  1. The lines $3x + 2y = k$ are parallel, and $k$ grows as they move up and to the right. The largest $k$ occurs where the line last touches the region, at a corner.

    This is the "sweeping parallel lines" idea from the concept, used in reverse.

  2. Corners: $(0,0) \to 0$, $(2,0) \to 6$, $(3,1) \to 11$, $(0,4) \to 8$.

    Only the corners need checking.

$11$, at $(3, 1)$.

A linear expression on a polygon is largest and smallest at corners.

22.3 Quadratic Inequalities

Hook

A ball is tossed upward and its height after $t$ seconds is $20t - 5t^2$ meters. For how long is it higher than $15$ meters? That's the inequality $20t - 5t^2 > 15$. The answer isn't one moment but a time window, and the tool that finds it is the same factoring you already know, read in a new way.

Concept

Move everything to one side so the other side is $0$, then factor. For $x^2 - x - 6 > 0$ we get $(x - 3)(x + 2) > 0$. A product is positive when both factors have the same sign and negative when they differ. Each factor changes sign only at its zero, so mark the zeros $-2$ and $3$ and check the sign of each factor in each interval:

$$\begin{array}{c|ccc} & x < -2 & -2 < x < 3 & x > 3 \\ \hline x + 2 & - & + & + \\ x - 3 & - & - & + \\ \hline \text{product} & + & - & + \end{array}$$

So $(x - 3)(x + 2) > 0$ exactly when $x < -2$ or $x > 3$. For $\ge$ we'd also include the zeros. Graphically, the upward parabola $y = (x-3)(x+2)$ is above the axis outside its roots and below it between them.

Interval notation writes such answers compactly: $[a, b]$ includes both ends, $(a, b)$ neither, $[a, b)$ just the left one. Unbounded intervals use $\infty$, which always takes a parenthesis because it isn't a number. "Or" becomes the union symbol $\cup$:

$$x < -2 \text{ or } x > 3 \quad\Longleftrightarrow\quad (-\infty, -2) \cup (3, \infty).$$

Fractions: never multiply both sides by an expression like $x - 3$, because you don't know whether it's positive or negative. Instead, move everything to one side, combine into a single fraction, and make a sign chart using the zeros of the numerator and the denominator. Zeros of the denominator are never included.

Already factored

Solve $(x - 1)(x + 4) < 0$.

  1. Zeros: $x = 1$ and $x = -4$.

    These split the number line into three intervals.

  2. Between them, e.g. $x = 0$: $(-1)(4) = -4 < 0$ ✓. Outside, both factors share a sign, so the product is positive.

    Testing one point per interval is enough.

$-4 < x < 1$, that is, $(-4, 1)$.

Practice with interval notation

Write in interval notation: (a) $x \le 2$; (b) $-1 < x \le 5$; (c) $x < -3$ or $x \ge 0$.

  1. (a) $(-\infty, 2]$.

    $2$ is included (bracket); $-\infty$ always gets a parenthesis.

  2. (b) $(-1, 5]$.

    Parenthesis for the strict end, bracket for the nonstrict end.

  3. (c) $(-\infty, -3) \cup [0, \infty)$.

    "Or" becomes a union of two intervals.

$(-\infty, 2]$; $\ (-1, 5]$; $\ (-\infty, -3) \cup [0, \infty)$

Factor, then read the chart

Solve $x^2 - 2x - 15 \ge 0$.

  1. $(x - 5)(x + 3) \ge 0$; zeros at $-3$ and $5$.

    Factor first, as with any quadratic equation.

  2. Product positive outside the zeros, negative between, and zero at them.

    An upward parabola is below the axis only between its roots.

  3. Include the zeros because of $\ge$.

    At the zeros the product is $0$, which satisfies "$\ge 0$."

$(-\infty, -3] \cup [5, \infty)$

A leading coefficient other than 1

Solve $2x^2 + x < 6$.

  1. Rewrite as $2x^2 + x - 6 < 0$ and factor: $(2x - 3)(x + 2) < 0$.

    Always get $0$ on one side before factoring.

  2. Zeros: $x = \tfrac32$ and $x = -2$. The product is negative between them.

    Test $x = 0$: $(-3)(2) < 0$ ✓.

$-2 < x < \tfrac32$, that is, $\left(-2, \tfrac32\right)$.

A perfect square

Solve $x^2 + 10x + 25 > 0$ and $x^2 + 10x + 25 \le 0$.

  1. $x^2 + 10x + 25 = (x + 5)^2$, which is $\ge 0$ always and $0$ only at $x = -5$.

    A square is never negative.

  2. $> 0$: every $x$ except $-5$. $\;\le 0$: only $x = -5$.

    The "between the roots" interval has shrunk to a single point.

$> 0$: $(-\infty, -5) \cup (-5, \infty)$. $\;\le 0$: $x = -5$ only.

No real roots at all

Solve $x^2 - 4x + 7 > 0$.

  1. The discriminant is $16 - 28 < 0$, so it doesn't factor over the reals. Complete the square: $(x - 2)^2 + 3$.

    Completing the square shows the smallest value directly.

  2. $(x-2)^2 + 3 \ge 3 > 0$ for every $x$.

    The parabola never reaches the axis.

All real numbers. (The inequality $x^2 - 4x + 7 < 0$ would have no solutions.)

The ball above 15 meters

For which times $t \ge 0$ is $20t - 5t^2 > 15$?

  1. $-5t^2 + 20t - 15 > 0$. Divide by $-5$ and flip: $t^2 - 4t + 3 < 0$.

    Dividing by a negative makes the leading coefficient positive, at the cost of flipping the sign.

  2. $(t - 1)(t - 3) < 0$, so $1 < t < 3$.

    Negative between the roots.

$1 < t < 3$: the ball is above $15$ m for $2$ seconds.

Three factors

Solve $x(x - 2)(x + 3) \le 0$.

  1. Zeros: $-3, 0, 2$, giving four intervals.

    Every factor contributes a zero.

  2. Signs from left to right: $x < -3$: $(-)(-)(-) = -$; $\;-3 < x < 0$: $(-)(-)(+) = +$; $\;0 < x < 2$: $(+)(-)(+) = -$; $\;x > 2$: $+$.

    Each time we pass a zero, exactly one factor changes sign, so the product alternates.

  3. Take the negative intervals and include the zeros.

    The inequality is nonstrict.

$(-\infty, -3] \cup [0, 2]$

A quartic in disguise

Solve $x^4 - 10x^2 + 9 < 0$.

  1. Let $y = x^2$: $y^2 - 10y + 9 = (y - 1)(y - 9) < 0$, so $1 < y < 9$.

    The expression is a quadratic in $x^2$.

  2. $1 < x^2 < 9$ means $1 < |x| < 3$.

    Taking square roots of nonnegative quantities preserves order, but $x$ itself may be negative.

  3. So $-3 < x < -1$ or $1 < x < 3$. Check: $(x-1)(x+1)(x-3)(x+3)$ alternates sign across $-3, -1, 1, 3$ and is negative on these two intervals.

    The full factorization gives the same sign chart.

$(-3, -1) \cup (1, 3)$

A rational inequality

Solve $\dfrac{x + 1}{x - 2} \ge 3$.

  1. Don't cross-multiply. Subtract $3$: $\dfrac{x + 1}{x - 2} - 3 \ge 0$, so $\dfrac{x + 1 - 3(x - 2)}{x - 2} = \dfrac{7 - 2x}{x - 2} \ge 0$.

    The sign of $x - 2$ is unknown, so multiplying by it might or might not flip the inequality.

  2. Critical points: $x = \tfrac72$ (numerator) and $x = 2$ (denominator). Signs: $x < 2$: $\tfrac{+}{-} = -$; $\;2 < x < \tfrac72$: $\tfrac{+}{+} = +$; $\;x > \tfrac72$: $\tfrac{-}{+} = -$.

    Numerator and denominator factors go on the same sign chart.

  3. Take $2 < x \le \tfrac72$: include $\tfrac72$ (value $0$), exclude $2$ (undefined).

    Check $x = 3$: $\tfrac41 = 4 \ge 3$ ✓; $x = 4$: $\tfrac52 < 3$ ✗.

$\left(2, \tfrac72\right]$

For fractions, move everything to one side and use a sign chart; zeros of the denominator are always excluded.

22.4 Absolute Value Inequalities

Hook

A factory makes bolts that are supposed to be $50$ mm long, and a bolt passes inspection if it's within $0.2$ mm of that. In symbols, a length $L$ passes when $|L - 50| \le 0.2$. Absolute value inequalities are just statements about distance: "within" and "farther than."

Concept

Since $|x - c|$ is the distance from $x$ to $c$:

$$|x - c| < r \iff c - r < x < c + r \qquad\text{(within } r \text{ of } c\text{: one interval)}$$

$$|x - c| > r \iff x < c - r \ \text{ or } \ x > c + r \qquad\text{(farther than } r\text{: two rays)}$$

The same holds with $\le$ and $\ge$, endpoints included. In general, $|M| < N$ becomes $-N < M < N$, and $|M| > N$ becomes $M < -N$ or $M > N$. Make sure you see why the second piece has its sign reversed.

Always isolate the absolute value first: in $4|x + 3| + 3 > 9$, subtract $3$ and divide by $4$ to reach $|x + 3| > \tfrac32$. Watch for impossible or automatic cases: $|M| < -1$ has no solutions, and $|M| > -1$ is always true.

Within a distance of zero

Solve $|x| < 4$.

  1. $|x|$ is the distance from $0$, so we need $x$ within $4$ of $0$: $-4 < x < 4$.

    "Less than" gives a single interval centered at $0$.

$(-4, 4)$

Farther than a distance

Solve $|x - 2| \ge 5$.

  1. $x - 2 \ge 5$ or $x - 2 \le -5$.

    At least $5$ away from $2$, on either side.

  2. $x \ge 7$ or $x \le -3$.

    Add $2$ to each piece.

$(-\infty, -3] \cup [7, \infty)$

Unwrap and solve

Solve $|2x + 3| \le 7$.

  1. $-7 \le 2x + 3 \le 7$.

    $|M| \le N$ means $M$ lies between $-N$ and $N$.

  2. $-10 \le 2x \le 4$, so $-5 \le x \le 2$.

    Subtract $3$, then divide by $2$, in all three parts.

$[-5, 2]$

Isolate first

Solve $3|x - 1| + 2 > 14$.

  1. $3|x - 1| > 12$, so $|x - 1| > 4$.

    Get the absolute value alone before removing it.

  2. $x - 1 > 4$ or $x - 1 < -4$, so $x > 5$ or $x < -3$.

    Farther than $4$ from $1$.

$(-\infty, -3) \cup (5, \infty)$

Go backwards: interval to absolute value

Write $-3 \le x \le 9$ as a single absolute value inequality.

  1. Center: $\dfrac{-3 + 9}{2} = 3$. Radius: $\dfrac{9 - (-3)}{2} = 6$.

    The interval is "within $6$ of its midpoint $3$."

  2. $|x - 3| \le 6$. Check: $3 - 6 = -3$ and $3 + 6 = 9$. ✓

    Unwrapping gives back the original interval.

$|x - 3| \le 6$

A negative coefficient inside

Solve $|5 - 2x| < 3$.

  1. $-3 < 5 - 2x < 3$, so $-8 < -2x < -2$.

    Subtract $5$ from all parts.

  2. Divide by $-2$ and flip both: $4 > x > 1$, that is, $1 < x < 4$.

    Rewrite with the smaller number on the left for clarity.

$(1, 4)$

Alternatively, $|5 - 2x| = |2x - 5|$, so you can avoid the negative coefficient entirely.

Count integers in a ring

How many integers $x$ satisfy $2 < |x - 1| \le 5$?

  1. $|x - 1| \le 5$: $-4 \le x \le 6$.

    Within $5$ of $1$.

  2. $|x - 1| > 2$: $x < -1$ or $x > 3$.

    More than $2$ away from $1$.

  3. Both: $-4 \le x < -1$ or $3 < x \le 6$. Integers: $-4, -3, -2$ and $4, 5, 6$.

    Overlap the two conditions, minding which endpoints are included.

$6$ integers

A sum of two distances

Solve $|x - 1| + |x + 3| < 6$.

  1. It's the distance from $x$ to $1$ plus the distance from $x$ to $-3$. For any $x$ between $-3$ and $1$ this sum is exactly $4 < 6$, so all such $x$ work.

    Between the two points, the two distances add up to the gap between them.

  2. $x > 1$: $(x - 1) + (x + 3) = 2x + 2 < 6$, so $x < 2$.

    To the right of both points, both absolute values open with a plus sign.

  3. $x < -3$: $(1 - x) + (-x - 3) = -2x - 2 < 6$, so $x > -4$.

    To the left of both, both open with a minus sign.

  4. Together: $-4 < x < 2$.

    The three pieces join into one interval.

$(-4, 2)$

Split the number line where each absolute value changes form; distance pictures give a quick check.

One half is automatic

Solve $|x^2 - 2x| < 3$.

  1. $-3 < x^2 - 2x < 3$: two quadratic inequalities at once.

    Unwrap the absolute value as usual.

  2. Left half: $x^2 - 2x + 3 > 0$, i.e. $(x - 1)^2 + 2 > 0$. Always true.

    Completing the square shows this half adds no restriction.

  3. Right half: $x^2 - 2x - 3 < 0$, i.e. $(x - 3)(x + 1) < 0$, so $-1 < x < 3$.

    A standard quadratic inequality from Section 22.3.

22.5 A Trivial Inequality

Hook

You have 20 meters of fence and want to enclose the biggest possible rectangle. A $9 \times 1$ pen has area $9$; a $6 \times 4$ pen has area $24$; a $5 \times 5$ square has area $25$. Why does the square win, every time? Write the sides as $5 + d$ and $5 - d$: the area is $25 - d^2$. The fact behind it is so simple it's almost embarrassing to state.

Concept

The Trivial Inequality:

$$x^2 \ge 0 \text{ for every real } x, \text{ with equality only when } x = 0.$$

It becomes powerful once you put something interesting inside the square. Since $(x - y)^2 \ge 0$, expanding gives $x^2 - 2xy + y^2 \ge 0$, that is,

$$x^2 + y^2 \ge 2xy, \qquad\text{with equality exactly when } x = y.$$

Minimizing quadratics. Complete the square: $x^2 + bx + c = \left(x + \tfrac b2\right)^2 + c - \tfrac{b^2}{4}$. The square is at least $0$, so the expression is at least $c - \tfrac{b^2}{4}$, reached at $x = -\tfrac b2$.

Working backwards is a fine way to discover a proof: start from the claim and simplify until you reach something obviously true. But it only proves the claim if every step can be reversed. When you multiply by a quantity, make sure it's positive; when you take square roots, make sure both sides are nonnegative.

Smallest value of a quadratic

Find the minimum of $x^2 - 6x + 11$.

  1. $x^2 - 6x + 11 = (x - 3)^2 + 2$.

    Half of $-6$ is $-3$, and $(x - 3)^2 = x^2 - 6x + 9$.

  2. $(x-3)^2 \ge 0$, so the expression is $\ge 2$, with equality at $x = 3$.

    The smallest possible square is $0$.

Minimum $2$, at $x = 3$.

Recognize a square

Show that $a^2 + 9 \ge 6a$ for every real $a$. When is it an equality?

  1. $a^2 + 9 - 6a = (a - 3)^2 \ge 0$.

    Move everything to one side and look for a perfect square.

  2. Equality when $a - 3 = 0$, that is, $a = 3$.

    A square is zero only when its base is zero.

$a^2 + 9 - 6a = (a-3)^2 \ge 0$; equality at $a = 3$.

Factor out the leading coefficient

Find the minimum of $2x^2 - 8x + 3$.

  1. $2(x^2 - 4x) + 3 = 2\big[(x - 2)^2 - 4\big] + 3 = 2(x - 2)^2 - 5$.

    Factor the $2$ out of the $x$ terms before completing the square.

  2. $2(x - 2)^2 \ge 0$, so the minimum is $-5$, at $x = 2$.

    A positive multiple of a square is still $\ge 0$.

Minimum $-5$, at $x = 2$.

The highest point

A ball's height is $-t^2 + 8t + 5$ meters after $t$ seconds. What is its greatest height?

  1. $-t^2 + 8t + 5 = -(t^2 - 8t) + 5 = -(t - 4)^2 + 16 + 5 = -(t-4)^2 + 21$.

    With a negative leading coefficient we look for a maximum.

  2. $-(t - 4)^2 \le 0$, so the height is at most $21$, reached at $t = 4$.

    Subtracting a square can only lower the value.

$21$ meters, at $t = 4$ seconds.

A fraction and its flip

Prove that $\dfrac{a}{b} + \dfrac{b}{a} \ge 2$ for positive $a$ and $b$.

  1. Since $ab > 0$, multiplying by $ab$ keeps the direction: the claim is equivalent to $a^2 + b^2 \ge 2ab$.

    This step is reversible because $ab$ is positive.

  2. $a^2 + b^2 - 2ab = (a - b)^2 \ge 0$. True, with equality when $a = b$.

    We've reached the trivial inequality; reverse the steps to finish the proof.

$\dfrac ab + \dfrac ba - 2 = \dfrac{(a - b)^2}{ab} \ge 0$, with equality when $a = b$.

Next in the book: Example 22-5 and Exercise 22-14.

Average beats geometric mean

Show that $\dfrac{a + b}{2} \ge \sqrt{ab}$ for $a, b \ge 0$, and use it to explain the fence puzzle from the hook.

  1. $\left(\sqrt a - \sqrt b\right)^2 \ge 0$ expands to $a - 2\sqrt{ab} + b \ge 0$, so $a + b \ge 2\sqrt{ab}$.

    Square roots of nonnegative numbers are real, so the trivial inequality applies.

  2. Fence: sides $w$ and $\ell$ with $w + \ell = 10$. Then $\sqrt{w\ell} \le \dfrac{w + \ell}{2} = 5$, so the area $w\ell \le 25$.

    Square both sides (both nonnegative).

  3. Equality needs $\sqrt w = \sqrt\ell$, a $5 \times 5$ square.

    The square inside the proof is zero only when the two quantities match.

$\dfrac{a+b}2 \ge \sqrt{ab}$; the best rectangle with perimeter $20$ is the $5 \times 5$ square, of area $25$.

This is the two-number Arithmetic-Geometric Mean Inequality, a preview of Volume 2.

A number plus its reciprocal

Find the smallest value of $x + \dfrac1x$ for $x > 0$.

  1. $x + \dfrac1x - 2 = \left(\sqrt x - \dfrac{1}{\sqrt x}\right)^2 \ge 0$.

    Expanding the square gives $x - 2 + \tfrac1x$.

  2. So $x + \dfrac1x \ge 2$, with equality when $\sqrt x = \dfrac{1}{\sqrt x}$, that is, $x = 1$.

    Check: $1 + 1 = 2$.

$2$, at $x = 1$.

Three squares at once

Prove $x^2 + y^2 + z^2 \ge xy + yz + zx$ for all real $x, y, z$.

  1. Double: the claim is $2x^2 + 2y^2 + 2z^2 - 2xy - 2yz - 2zx \ge 0$.

    Multiplying by $2$ is reversible and sets up perfect squares.

  2. The left side equals $(x - y)^2 + (y - z)^2 + (z - x)^2$.

    Each variable appears in two of the squares, contributing $2x^2$ and so on.

  3. A sum of squares is $\ge 0$, with equality only when $x = y = z$.

    Every term is nonnegative, so the sum is too.

$2(\text{LHS} - \text{RHS}) = (x-y)^2 + (y-z)^2 + (z-x)^2 \ge 0$.

Minimum in two variables

Find the minimum of $x^2 + y^2 - 4x + 6y + 20$ over all real $x$ and $y$.

  1. Complete the square in each variable: $(x - 2)^2 - 4 + (y + 3)^2 - 9 + 20$.

    The $x$ and $y$ parts don't interact, so handle them separately.

  2. $= (x - 2)^2 + (y + 3)^2 + 7 \ge 7$.

    Both squares are at least $0$.

  3. Equality at $x = 2$, $y = -3$.

    Both squares are $0$ there at the same time.

Minimum $7$, at $(2, -3)$.

One equation, two unknowns, one answer

Find all real $x, y$ with $x^2 + y^2 + 2 = 2x + 2y$.

  1. Rearrange: $(x^2 - 2x + 1) + (y^2 - 2y + 1) = 0$, so $(x - 1)^2 + (y - 1)^2 = 0$.

    Split the constant $2$ to complete both squares.

  2. Two nonnegative numbers add to $0$ only if both are $0$: $x = 1$, $y = 1$.

    If either square were positive, the sum would be positive.

$x = 1$, $y = 1$

A sum of squares equal to zero forces every square to be zero.
